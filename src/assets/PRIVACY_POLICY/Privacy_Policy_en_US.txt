2. CATEGORIES OF DATA PROCESSED LOCALLY IN THE APPLICATION
================================================================================

To perform wind action calculations and generate formal structural engineering reports, the Software processes in volatile memory (RAM) the information actively entered by the user within the calculation tabs and project settings dialog:

a) TECHNICAL & PROJECT IDENTIFICATION DATA:
 - Project title and identification;
 - Structural engineer or responsible technical designer name;
 - Professional license and ART/RRT registration number (CREA/CAU);
 - Client or contracting organization name;
 - City and State (UF) of building construction site.

b) STRUCTURAL, GEOMETRIC & AERODYNAMIC PARAMETERS:
 - Building geometry (clear span b, length a, eave height h, roof pitch θ);
 - Basic wind speed (V0), topographic factor (S1), terrain roughness factor (S2), and statistical factor (S3);
 - Opening areas, permeability ratios, and aerodynamic coefficients (Cpe, Cpi).

NOTICE REGARDING THIRD-PARTY PERSONAL DATA:
The structural engineer name, professional CREA/ART license number, and client name entered into the system may constitute personal data under the LGPD and GDPR. Such data is provided at the sole discretion of the user, remains strictly within the local runtime memory of the application, and is output only into reports and export files deliberately saved by the user.

3. LOCAL FILE STORAGE & INSTALLER CONFIGURATION
================================================================================

3.1. PROJECT & REPORT STORAGE:
In version 2026.11.8.0, the Software performs zero background or automated hidden file writes. Disk writes occur exclusively when the user manually triggers the "Save Project (.json)" command, exports calculation reports in HTML, Markdown, or JSON, or designates an output file via the CLI utility (eolo-cli --output). Files are saved strictly to the folder and drive chosen by the user.

3.2. DIRECT INSTALLER LANGUAGE CONFIGURATION:
If the application is installed via the direct standalone installer (Inno Setup), the setup wizard records a local configuration file containing solely the selected UI language code ("pt_BR" or "en_US") at %APPDATA%\EoloPlatform\language_config.json. Upon uninstallation, this directory and the associated local application data directory (%LOCALAPPDATA%\EoloPlatform) are completely removed.

3.3. FUTURE LOCAL DATABASE PERSISTENCE:
The codebase includes structured support for local SQLite persistence stored at %APPDATA%\EoloPlatform\eolo_data.db. If enabled in future releases, the database operates in a strictly disconnected, local manner under the user's custody.
